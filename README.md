# 🛒 PhiMart – E-commerce API (Django REST Framework)

PhiMart is a backend **E-commerce REST API** built using **Django Rest Framework (DRF)**.  
The project is designed for learning and demonstrating real-world backend concepts such as authentication, product management, cart handling, orders, and API documentation.

## 🚀 Features

- 🔐 User Authentication & Authorization (JWT, Djoser)
- 🛍️ Product Management (CRUD)
- 🖼️ Product Image Upload
- 🗂️ Category Management
- 🛒 Cart & Cart Items
- 📦 Order Management
- ⭐ Product Reviews
- 🧑‍💼 Admin Dashboard
- 📄 Swagger & ReDoc API Documentation
- 🐞 Django Debug Toolbar (Development)

---

## 🧰 Tech Stack

- **Backend:** Django 6, Django REST Framework
- **Authentication:** JWT, Djoser, Social Auth
- **Database:** SQLite / PostgreSQL (configurable)
- **API Docs:** drf-yasg (Swagger & ReDoc)
- **Others:** Pillow, Django Filters, Nested Routers
